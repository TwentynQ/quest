КВЕСТ «РОДНАЯ МОЯ ДЕВЧОНКА» — ОБНОВЛЁННАЯ СБОРКА

Файлы:
- index.html
- rodnaya-v2.mp3 (должен лежать рядом с index.html)

Изменения:
- В загадке про полусладкое нет упоминания прохлады/холодильника.
- Кнопка у загадки на колонку: «Я нашла».
- Собранные цифры видны на каждом этапе, включая музыкальный экран.
- Песня запускается с телефона Альбины через встроенный аудиоплеер; можно вывести звук на JBL через Bluetooth.
- Под плеером постоянно видна кнопка «Песня закончилась — продолжить». Она не зависит от события окончания MP3, чтобы тестирование не застревало, но текст подсказывает дождаться окончания песни.
- После нажатия открывается ввод цифры 9.
- Если аудио не загружается, появится сообщение с объяснением проверить, что MP3 и HTML лежат рядом в GitHub Pages.

Публикация:
1. Распаковать архив.
2. Загрузить index.html и rodnaya-v2.mp3 в корень GitHub Pages репозитория.
3. Открыть опубликованный HTTPS-адрес на iPhone в Safari.
4. Провести тест от начала до конца. Не записывать NFC до успешного теста.

Механика песни:
Альбина нажимает «Я нашла» → экран песни → включает MP3 на своём телефоне (при необходимости подключает JBL по Bluetooth) → слушает композицию → нажимает «Песня закончилась — продолжить» → вводит цифру 9 со скретч-наклейки.

Ответы организатора:
бутылка 6; ребус КОЛОНКА; JBL 9; дата первого поцелуя 28.06.2026 даёт 8; «Мин сине яратам» — 3 слова; 19–6–11–22 = СЕЙФ; код 6983.
