# Квест для Альбины — версия 16

В архив уже включена присланная песня. Файл переименован в `rodnaya-v2.mp3`, чтобы совпадать с путём в HTML. Аудио не перекодировано и не изменено.

## Запуск

Распакуй архив и размести рядом `index.html`, `love-is-scratch.png` и `rodnaya-v2.mp3`. В квесте откроется именно эта песня, без необходимости выбирать файл вручную. При проблемах загрузки остаются повторная загрузка и выбор файла песни.

На iPhone надёжнее открыть размещённую страницу в Safari, а не HTML-предпросмотр приложения «Файлы». Автоматически музыка не запускается: после подключения колонки нажми воспроизведение.

Для отдельного HTML используй `Quest_Albina_Parchment_v16.html`: картинка и шрифты встроены, а песня загружается из соседнего `rodnaya-v2.mp3`. Песня включена именно в ZIP; если использовать только отдельный HTML без соседнего аудиофайла, её можно выбрать на устройстве.

## Последние изменения

Упоминания марки колонки убраны из всех текстов интерфейса. После «Я нашла» нужно подключиться к колонке через настройки Bluetooth, вернуться в квест и нажать «Подключилась». HTML не подключает устройство автоматически и не проверяет физическое соединение.

На музыкальном экране остаются «Иди ко мне скорее 🤗» и «Колонка подключена. Нажми воспроизведение — послушаем вместе».

Задание с цифрой теперь говорит только «Найди нужную цифру на колонке». Указание, где именно приклеена цифра, удалено.

Подпись картинки: «Мой внутренний мальчик любит радовать твою внутреннюю девчонку». На вводе кода сейфа нет строки «Твои находки» и верхнего счётчика с готовым кодом. Остальные задания, ответы, обязательное подключение, книжные рамки, игра букв, эффект печатной машинки, подсказка за поцелуй, личные фразы, первая встреча и сохранение прогресса не изменены.

Сохранение совместимо с версиями 10–15 при замене страницы по тому же адресу в том же браузере. Перезапуск на финале сбрасывает прогресс и подтверждение подключения. Перед вручением проверь звук через колонку и настоящий сейф. Код находится в клиентском HTML; не используй его для других ценных вещей. Лицензии встроенных шрифтов включены в HTML и архив.
